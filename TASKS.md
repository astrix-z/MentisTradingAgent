## Исправлено

- **T01 (был P1).** Backend не проверялся строгим mypy: `backend/pyproject.toml`
  объявляет `strict = true`, но хук `local-mypy` запускал `uv run mypy backend/app`
  **из корня репозитория**, где `[tool.mypy]` не читается вообще, — то есть без
  `strict` и без `exclude` (28 файлов против 22). Теперь хук и новый шаг в
  `test-backend.yml` запускают одну команду `uv run --directory backend mypy app`, а
  устаревший `# type: ignore[arg-type]` в `strategy_catalog.py` удалён. Проверено:
  команда возвращает 0, временная неаннотированная функция в `backend/app` валит её
  (`no-untyped-def`). **Побочно:** в этом чекауте вообще нет `.git/hooks/pre-commit`
  (`prek install` не запускали), поэтому локальные хуки тут ничего не проверяли — иначе
  устаревший игнор не дожил бы до сегодня. Коммит `ab7ecc9`.
- **T02 (был P2).** `tsc` не проверял типы тестов: `tsconfig.build.json` исключает
  `tests/**/*.ts`, а `tsconfig.json` просил `lib: ES2020`, из-за чего
  `trading-contract.spec.ts:169` (`split("/").at(-2)`) не компилировался. `target`/`lib`
  подняты до ES2022, добавлен скрипт `typecheck` (`tsc -p tsconfig.json --noEmit`),
  хук `local-tsc-check` и шаг в `playwright.yml`. Проверено: до — TS2550, после — 0,
  а временный файл в `frontend/tests` с ошибкой типа валит проверку. Коммит `986b6ff`.
- **T05 (был P2).** Живой e2e заканчивался двумя падениями с `ECONNREFUSED`, и причин
  было две. Mailpit живёт в профиле `extras`, а `compose.override.yml` **жёстко ставил
  `SMTP_HOST: mailpit`, но оставлял `EMAILS_FROM_EMAIL` пустым**, — а `send_email` без
  него ассертит, то есть стек просил складывать письма в mailpit и делал отправку
  невозможной. Адрес получил локальный дефолт, а тесты, читающие письмо, теперь
  **скипаются** с текстом, называющим причину, вместо падения. Проверено на живом
  стеке: 85 passed, 0 падений; с остановленным mailpit — 5 passed, 2 skipped с внятной
  причиной; бэкенд-сьют при той же настройке — **201 passed**. `development.md`
  описывает оба рецепта. Коммит `466e2e5`.
- **T03 (был P3).** `bun run lint` оставлял несвязанный diff в отслеживаемой фикстуре
  `frontend/tests/fixtures/strategy-catalog.json`: генератор разворачивает короткие
  массивы (`indent=2`), Biome сворачивает. Фикстура исключена в `biome.json` рядом с
  остальными сгенерированными артефактами, а генератор стал идемпотентным:
  `published_at` переносится из прежнего файла, когда остальное не изменилось. Проверено:
  два прогона генератора подряд дерево не пачкают; `lint` сообщает «Fixed 3 files», и ни
  один из этих трёх не отслеживается. Коммит `26f99a2`.
- **T04 (был P3).** Biome ругался на артефакты e2e (`playwright/.auth/user.json`,
  `test-results/.last-run.json`) и переписывал их. Включена VCS-интеграция
  (`vcs.enabled` + `clientKind: git` + `useIgnoreFile`), так что `.gitignore` стал
  единственным источником истины; заодно закрылся третий такой файл —
  `frontend/openapi.json`, которого в задаче не было. Проверено: нарочно
  «неформатированный» JSON в этих трёх файлах больше не замечается (81 файл вместо 84),
  и `biome check ./` зелёный **после** живого e2e. Коммит `ef613c6`.
- **T06 (был P3).** У `/working-symbols` не было живого теста. Добавлен
  `frontend/tests/working-symbols.spec.ts`, устойчивый к состоянию: он принимает и
  таблицу с сортировкой, и сообщение «The agent has not published a symbol list yet», и
  падает только если страница сломалась или не может достучаться до агента.
  **Побочно:** именно эта ветка («не опубликовано») не была покрыта нигде — mock-сьют
  проверяет то же для страницы Strategy, но не для этой. Проверено на **обеих** ветках:
  с опубликованным документом и с временно испорченным в Redis (`available=False`),
  после чего документ восстановлен байт-в-байт. Живой сьют: 86 passed. Коммит `e0764b3`.
- **T07 (был P2).** `agent/README.md` заявлял проверку `mypy agent tests`, которая падала
  на 6 давних ошибках в тестах. Ошибки починены по-настоящему — `parsed[Model]()`
  разворачивает `from_dict` (он `Optional`), `reported()` проверяет `isinstance`,
  Redis-клиент аннотирован там, где `from_url` возвращает `Any`, и два узких
  `# type: ignore[misc]` с объяснением на `hgetall` (так же поступает продакшен-код).
  Проверка добавлена хуком `local-mypy-agent` и **обязана** запускаться из каталога
  агента: из корня mypy не находит `agent/pyproject.toml` и молча теряет `strict`
  (проверено пробой — неаннотированная функция проходит из корня и падает из `agent/`).
  Проверено: `cd agent && uv run mypy agent tests` → 0; `prek run local-mypy-agent`
  проходит, а с искусственной ошибкой типов в тесте — падает.
